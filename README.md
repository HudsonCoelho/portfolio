📖 Sobre o Projeto
Este site é mais do que um currículo comum. Ele foi desenvolvido para ser uma experiência imersiva, mostrando minhas habilidades de front-end e back-end de uma forma criativa e única.

💡 Funcionalidades que você vai encontrar:

📜 Databook Card: Um cartão de informações ninja com meus dados profissionais e um gráfico de "poderes" (habilidades).

🗡️ Arsenal de Jutsus: Uma lista de minhas principais tecnologias, representadas por elementos de chakra (Raio, Fogo, Vento, etc.).

🏆 Pontuação Ninja: Um sistema de progressão baseado nas "missões" (projetos) que já completei.

⚙️ Missões Ninja: Filtro de projetos por status e rank, detalhando tecnologias e conhecimentos aplicados em cada um.

🤔 Quiz de Clã: Um quiz interativo que revela seu "clã ninja" de desenvolvimento, conectando seu estilo a clãs famosos como Uchiha (Front-end) ou Senju (Back-end).

🍥 Invocação de Ninjas: Uma integração com a API dattebayo-api que invoca um personagem famoso de Naruto aleatoriamente a cada clique.

👁️ Sharingan Interativo: Um efeito visual com os olhos Sharingan que seguem o movimento do mouse.

🎵 Modo Imersivo: Um botão para tocar ou pausar a música tema de fundo, aumentando a atmosfera ninja.

📱 Design Responsivo: Totalmente adaptado para funcionar bem em desktops, tablets e smartphones.

🚀 Como Executar o Projeto Localmente
Quer ver o código rodando na sua máquina? É bem simples:

Clone o repositório:

bash
git clone https://github.com/HudsonCoelho/portfolio.git
Acesse a pasta do projeto:

bash
cd portfolio/Portfolio
Abra o arquivo index.html no seu navegador.

Você pode fazer isso clicando duas vezes no arquivo ou usando uma extensão como o "Live Server" do VS Code para uma experiência melhor.

Pronto! O site estará funcionando localmente.
